# Schwabdev-Context
 
Trader Context is a unified wrapper for backtesting and live trading. Write one strategy function. Backtest it on cached minute candles, paper-trade it on live data, or deploy it against your real Schwab account - the strategy code is identical in all three.

To install run `pip install schwabdev[context]`

Schwabdev Trader Context documentation is hosted in the [main Schwabdev docs](https://tylerebowers.github.io/Schwabdev/?source=pages%2Fwelcome.html).
